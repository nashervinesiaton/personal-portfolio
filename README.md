# Nash Siaton Portfolio

Personal portfolio for Nash Ervine Siaton, an aspiring web developer and BSIS
student at West Visayas State University.

## Stack

- React
- Vite
- Tailwind CSS
- Motion
- React Router

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## Content

- Profile and resume data: `src/data/profile.js`
- Project case studies: `src/data/projects.js`
- Uploaded CV: `public/Nash-Ervine-Siaton-CV.pdf`
- Main routes: `src/pages`

The contact form currently prepares a message in the visitor's email client
with `mailto:`. It does not send messages through a server.
